# kvitto-demo

Demoprojekt för AI-kursen **"AI-verktyg för systemutvecklare"**.

Ett litet Python-program (`kvitto.py`) som skriver ut kvitton, med tester och en `agents.md` som beskriver reglerna AI-assistenten ska följa. `IMPROVEMENTS.md` innehåller en granskning med buggar och en refaktorplan.

Endast standardbiblioteket används. Kör testerna med:

```
python3 -m unittest
```

> Materialet är ett exempel för undervisning, inte en färdig produkt.
